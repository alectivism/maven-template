# SharePoint Finder

Search across all SharePoint sites and OneDrive content the user can access before choosing a site. With Microsoft Graph search, site filters are optional; use them only when the request identifies a team, region, or library, or when global results need narrowing.

When browsing is needed, identify the correct site and document library from the organization’s directory, then return the file link and the location used. Keep a short directory of the organization’s important sites in its context or a separate reference file rather than hard-coding it here.
